# Assertion-block sites this run OPENS but no tracker BINDS (#lzktblockwalk).
#
# One line per SITE — `<fixture>|<path>` TAB reason — so every entry fails as
# stale INDEPENDENTLY the day its site is bound. A per-fixture or per-area excuse
# would absorb the rest of that group silently, which is the rot this ledger
# exists to refuse.
#
# The guard in scripts/check-conformance-coverage.sh enforces BOTH directions:
# an UNBOUND site missing from here is an error, and an entry here that the run
# bound — or that the corpus no longer carries — is a stale excuse and also an
# error.
#
# Both directions together are still not enough, because they only check that this
# file and the run AGREE, and ANY CONSISTENT PAIR satisfies that: a commit that
# detaches N binds and writes the N matching entries passes forward, backward and
# stale-gone, and the magnitude rung misses it too because those sites are still
# DECLARED, merely no longer bound. So the guard also pins this file's SIZE —
# EXPECTED_LEDGERED_BLOCKS, an EXACT equality (#lzledgerceiling, made exact in
# #lzledgerratchet).
#
# Exact means BOTH directions fail, and the line count here is part of the
# contract either way:
#
#   adding a line      needs the pin raised in the same commit, and the pin is
#                      where you get asked why the block cannot be bound at all.
#   removing a line    needs the pin LOWERED in the same commit. A pin left above
#                      the real size is slack, and slack is what lets a later
#                      commit detach binds and write their own excuses with every
#                      rung still green. A one-sided ceiling permitted this
#                      silently and so re-armed the attack once per migration.
#
# TWO reason classes, and they are not the same kind of claim:
#
#   unreachable    the replay never reaches the step, so no tracker CAN bind the
#                  block. 25 sites over the six fixtures ReactiveGraphConformance
#                  Test.EXPECTED_SKIPS names — five `merge_cell` fixtures whose op
#                  this binding does not model (the fix is upstream, #lzmergefeed)
#                  and one novel `drain_exhausted` key. lazily-zig, lazily-cpp and
#                  lazily-dart each independently landed 25 entries over the same
#                  six fixtures; three bindings converging on the same number from
#                  their own corpora is the strongest evidence available that this
#                  set is the real one. Clearing an entry here means the op is
#                  genuinely modelled — never widen it to make a red build green.
#
#   bind-pending   the block IS reachable and the runner DOES assert its keys, by
#                  direct indexing rather than through AssertionKeys. So the keys
#                  are compared, but nothing books the bind and nothing enforces
#                  the unread/unasserted/key-set rungs over them. 496 sites across
#                  13 areas. This is PHASE 2 of #lzktblockwalk and it is NOT done:
#                  each entry is a runner that needs migrating, not a gap that was
#                  investigated and dismissed. Before this walk widened, these 540
#                  sites were not excused — they were INVISIBLE, outside a rung
#                  that saw 18 of the corpus's 749. An entry is a debt that is now
#                  counted; do not read it as a waiver.
#
#                  Migrated so far (#lzktbindpending): ipc/root 1, familysync 3,
#                  protobuf 6, membership 9, message-passing 9, lossless-tree 16
#                  — 44 sites.
#
#                  There is NO typed count of this class any more. A count that
#                  mirrors the population the set equality already fixes carries no
#                  information — equal sets have equal counts — and it was a second
#                  edit site that had to move in lockstep (#lzledgerceiling). The
#                  ceiling on this file's total SIZE carries the policy instead, and
#                  it bounds both classes rather than only this one.
#
# Do not add an entry for a block you could bind. Do not hand-sort or regenerate
# this file wholesale to clear a red — the red names the site, and the site names
# the runner.
